## 🚀 Featured Projects

### 1. Exploratory Data Analysis on E-commerce Sales
* **Python + SQL**
    * **Goal:** To analyze sales trends and customer purchasing behavior using a dataset of 50k+ transactions.
    * **Tech Stack:** Python, Pandas, Seaborn, Jupyter Notebook.
    * **Key Insight:** Discovered a 15% drop in weekend sales, leading to a recommendation for targeted weekend email campaigns.
    * **Link to Code:** [Click here to view notebook](./Project/Retail-Data-Analysis/)

### 2. Exploratory Data Analysis on Playstore Apps
* **Python**
    * **Goal:** To perform data cleaning, feature engineering, and exploratory data analysis on the Google Play Store dataset to uncover app success factors.
    * **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.
    * **Key Insight:** Analyzed app ratings, reviews, and categories to identify trends that drive user engagement and higher installations.
    * **Link to Code:** [Click here to view notebook](./Project/Playstore-Data-Analysis/)

### 3. Exploratory Data Analysis on F1 Data(2018-2024)
* **Python + SQL + Power BI**
    * **Goal:** An end-to-end data analytics project exploring 7 seasons of Formula 1 racing data — from raw API ingestion to SQL analysis and interactive Power BI dashboards.
    * **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook, SQL, Power BI.
    * **Key Insight:** Analyzed driver and team performances, plotted consistency graphs, pole to win conversion along with circuit and pit stop analysis.
    * **Link to Code:** [Click here to view notebook](./Project/F1-race-Analytics/)

### 4. Exploratory Data Analysis on Nifty50 Index(2020-2024)
* **Python**
    * **Goal:** An exploratory data analysis of 30 Nifty 50 stocks across 5 years — covering COVID recovery, sector performance, risk-return tradeoffs, and stock correlations.
    * **Tech Stack:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook.
    * **Key Insight:** Analyzed Nifty50 price movements along with top 30 stocks, quantifying the impact of Covid-19 crash on index and sector performance, plotting recovery and performing CAPM analysis.
    * **Link to Code:** [Click here to view notebook](./Project/Nifty50-Analysis/)
